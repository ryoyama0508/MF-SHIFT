# medicalforce向けExcelシフト変換ツール v3（実ファイル対応）

> **推奨:** Web版（Next.js / Vercel）は `npm run dev` または Vercel デプロイ後の URL から利用してください。手順は [README.md](README.md) を参照。設定ファイルは `data/` 配下です。以下は旧 Mac CLI 手順です。

## 目標と処理範囲

クリニックで調整した原本の `.xlsx` を読み、月別シートから「日付×スタッフ×セルの文字×背景色」を抽出し、以前提供された medicalforce のシフトインポート雛形（7列）に変換します。スタッフのMF IDは `staff_registry.csv`（Web版は `data/staff_registry.csv`）と `mf_staff_master.csv` を利用します。

## 毎月の使い方（Mac・旧CLI）

1. `ExcelからMFシフトへ変換.command` を開き、完成したExcelと対象のシート名（例：`2026.12`）を指定します。Python 3が必要です。
2. ブラウザで月次シフト確認画面が開きます。スタッフを切り替え、未設定のMF登録名を選びます。原本に列がある人が対象で、今月扱わない列には「今月の対象外」を指定できます。
3. 「表示」で空欄の色や勤務記号を選び、「表示中をすべて選択」して勤務・非勤務をまとめて指定します。個別の日も選べます。「候補を採用」の時刻は原本の時刻を優先し、片側の省略にはスタッフ設定、未設定なら10:00または19:00を使います。候補の時刻と休憩を確認してから採用してください。
4. 要確認の日と勤務者のIDを確定し、最下部の確認欄にチェックを入れ、「月次CSVをダウンロード」を押します。原本のスタッフ列順で、各人の勤務日が日付順に並びます。非勤務の日は行を作りません。
5. Medical Forceの「シフト編集」→「CSVメニュー」→「入力用テンプレートをアップロード」から保存したCSVを選択します。

登録名「山本凌」のIDは、ご指定の山本亮さんに対応付けています。Excel見出しは「山本亮」（空白可）で照合できます。「山本」だけの見出しは同姓の候補がいるため画面で選択します。クリニックIDはArk Clinic固定です。

設定ファイルで判定がすべて確定している月は、同じ形式の `medicalforce_import.csv` も自動生成します。確認画面で編集した場合は、画面からダウンロードしたCSVが編集後の内容です。確認画面は `output/対象シート名/月次シフト確認.html` からも開けます。

ターミナルからは以下でも実行可能です。

```bash
python3 mf_shift_converter.py \
  --input '/path/to/シフト原本.xlsx' \
  --sheet '2026.11' \
  --out ./output/2026.11
```

## 設定のしかた

### `staff_registry.csv`

| 列名 | 意味 | 例 |
|---|---|---|
| 部署 | 同姓スタッフがいる場合の区別 | 外科 / AGA / Ns / Cs |
| Excel名 | 4行目に出る短いスタッフ名。**Excel列番号は不要** | 加藤 |
| MF登録名・スタッフID | MFから出力したマスターの氏名・ID | 該当スタッフのフルネーム／UUID |
| ID確認 | MFとの紐付けを確認したら `確認済` | 確認済 |
| 対象 | `1` 取り込み対象、`0` 意図的に対象外 | 1 |
| 空欄の扱い | `勤務` / `無視` / `要確認` | 勤務 |
| 通常出勤・通常退勤 | 白い空欄・`-18` などの補完用。必須になる場合あり | 10:00 / 19:00 |
| 休憩開始・休憩終了 | 任意。両方セットで指定 | 12:30 / 13:30 |

**前回の対応表を移行済み**。ただし `確認済` は前回の照合で確定したもののみで、吉武・中島・山田等の複数ID候補や新規スタッフは未承認のままです。同姓の「加藤」は外科・Nsで区別します。スタッフ位置が月ごとにずれても名前と部署から再検出します。

### `config.json`

- `gray_means_off_verified`: 灰色が休みの意味だと確認できたら `true`。例外として灰色に `-19` などの明確な時刻がある場合は**時刻を優先**します。
- `decimal_hours_verified`: `-17.5` の小数点を30分として扱うことが確認できたら `true`。
- `work_rules_verified`: 表記・背景色・勤務時間のルールをクリニックに確認できたら `true`。これが `false` の場合は画面で確認してダウンロードします。
- `text_codes`: 特殊文字のルール。**明示的な確認後のみ** `"学会": "work"`、`"明": "off"` 等を設定してください。未指定の場合は要確認で止まります。
- `drawing_day_decisions`: 図形の「休診日」等の扱い。例：2026年11月29日の図形について、全スタッフ非勤務と確認した場合は `"2026-11-29": "off"`、診療区分の注記などで全スタッフ休みではないと確認した場合は `"2026-11-29": "note_only"`。未設定では停止。
- `merged_cell_codes`: 結合セルの「全体MTG」等が全員の通常勤務であると確認できた場合 `"全体MTG": "work"`。未設定は要確認。

これらは**未確認のまま true にしたり、コードを追加しないでください**。

## 新しく対応した実ファイルの特徴

- 2025.1～2026.12の月別24シート、その他2シート。タブ名と表題A1が異なるシートは止めます（`2024.1 NS用シフト` は表題が `2023年1月`）。
- 1日が5行目、氏名が4行目。途中にある日付の再掲列、空き列、部署ブロックは社員として扱いません。
- セルのふりがな（ルビ）を本文の文字と誤認しないようにしています。
- Excelのテーマ色と色の濃淡をRGBに換算します。灰色は `#808080`、`#BFBFBF`、`#A6A6A6` など複数あります。
- `-18`、`ｰ１７`、`11-`、`10-19`、`-17.5` などを解析。明示的な時刻はグレー背景より優先。`-17.5` は確認設定必須。
- `休`、`希`、`有`、`有休`、`夏`などは暫定的な非勤務表記として認識。正式な意味はクリニックに確認してください。
- 図形「休診日」を日付付きで検出。2026.11では11月29日、また2026.7には7月8日の結合セル「全体MTG」があります。
- 日付に `20祝` と記載された場合も解析。11月に残る31日目の行は取り込みません。
- 1か月の勤務・休日の記載が0～1件程度のスタッフ列は、退職・未使用の可能性があるため確認対象にします。

## 出力ファイル

| ファイル名 | 目的 |
|---|---|
| シート一覧.csv | Excelに含まれるタブ一覧 |
| スタッフ照合.csv | 列・短い名前・ID・確認状況の一覧 |
| スタッフID対応表_追記候補.csv | 新しいスタッフを追記した設定用CSV候補 |
| セル別判定.csv | 1マスごとの色・文字・解釈・理由・勤務時刻 |
| 確認事項_集約.csv | 確認が必要な論点をスタッフ単位で集約 |
| 確認事項.csv | 未確定項目の詳細全件 |
| 勤務候補_確認用.csv | **MFインポートには使えない**列名で出した仮の勤務行 |
| report.json | 対象シート・人数・作成可否・図形・結合セル検出結果 |

## インポート前の運用上の注意

1. IDのないスタッフや別ID候補は必ず確定し、不要なスタッフだけ `対象=0` とします。
2. 白い空欄・灰色の意味、通常出退勤時間、休憩の有無をクリニックに確認します。
3. `当直`・`明`・`学会`・`AM出`・`全体MTG` は個別に勤務扱いとするかどうかの確認が必要です。
4. 2026年11月29日の「休診日」が全員休みなのか、一部の診療科だけの話なのか確認します。
5. medicalforce側で**既存シフトを上書きするのか、追記するのか**はこのExcelやCSVのヘッダーからは分かりません。本番前にMF担当者に確認し、必ず少数データでテストします。

`REAL_SHIFT_XLSX='/path/to/原本.xlsx' python3 -m unittest test_converter.py` で、この原本を使用した読み取りテストができます。
